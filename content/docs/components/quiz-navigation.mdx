---
title: QuizNavigation
description: Back/Next controls for the active step.
---

## Purpose

Standard funnel navigation. Next disables automatically until the
current step is answered (via `isStepAnswered` in the engine); Back is
hidden on the first step since there's no history yet.

## Installation

```bash
pnpm dlx shadcn@latest add @quiz-ui/quiz-navigation
```

## Usage

```tsx
<QuizNavigation />
```

```tsx
<QuizNavigation nextLabel="Continue" backLabel="Go back" />
```

## Props

| Prop        | Type      | Default  | Description                              |
| ----------- | --------- | -------- | ---------------------------------------- |
| `nextLabel` | `string`  | `"Next"` | Label on the advance button.             |
| `backLabel` | `string`  | `"Back"` | Label on the back button.                |
| `hideBack`  | `boolean` | `false`  | Hide Back entirely, even on later steps. |
| `className` | `string`  | —        | Merged onto the wrapper.                 |

## Notes

- A step is "answered" per `isStepAnswered` in the engine: any
  non-empty value, unless the step sets `required: false`, in which case
  it's always considered answered.
