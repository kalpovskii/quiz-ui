```bash
npx shadcn@latest add @quiz-ui/quiz-dialog
```

Depends on: `@quiz-ui/quiz-cn` (installed automatically).

## About

Modal-embedded funnel wrapper, on Radix Dialog.

See `content/docs/getting-started.mdx` for how funnels are assembled end
to end, and `app/example/` in this repo for a full working composition.
