## Installation

```bash
npx shadcn@latest add @quiz-ui/quiz-choice
```

Depends on: `@quiz-ui/quiz-core`, `@quiz-ui/quiz-cn` (installed automatically).

## About

Single- and multi-select answer cards, on Radix RadioGroup/Checkbox.

See `content/docs/getting-started.mdx` for how funnels are assembled end
to end, and `app/example/` in this repo for a full working composition.
